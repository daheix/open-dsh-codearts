# dsh-codearts 缺陷记录（2026-11-01 实测定位）

## 缺陷①：工具返回值序列化失败（阻断读路径）
- 现象：`codearts_status`/`codearts_goal list|start|control` 返回 `invalid output: value is not lossless JSON`
- 根因：`lib/index.js` 各 handler 返回 `{ goal: ... }`/`{ goals: ... }` 快照含 undefined 字段，DSH 宿主无损 JSON 编码器拒绝
- 已施缓解：安装态 `lib/index.js` 打 `lossless()` 消毒补丁（JSON.parse(JSON.stringify())），**下轮会话/插件重载生效**（本会话模块已缓存）
- 正确修法：源码（src/）层 sanitizer + 单测断言返回值无 undefined

## 缺陷②：双监督注册表分裂（架构级，非 bug 但需裁决）
- 官方工具 = `goal-supervisor.js`（M3 移植），注册表 `~/.dsh-codearts/goals/`（goal-* 命名）
- 旧桥守护 = codearts-bridge 4577，注册表 `~/.codearts-bridge/goals/`（gmvw* 命名，今日 W1~W6 全部波次在此运行）
- 工具查旧注册表目标报"不存在"是其注册表视角的正确行为；两系统互不可见
- 需裁决：收敛到单一监督引擎（建议新引擎为正，旧守护降级为兼容层或退役）

## 缺陷③：新引擎 tick 未发生（阻断写后执行）
- 实测：goal_start 成功落盘（state=active）但 `tuiPid=0`、`injections=0` 持续 9+ 分钟——引擎 sweep 未拉起 PTY
- 待查：harness 插件进程内 setInterval 是否注册成功 / spawn 失败静默吞错
